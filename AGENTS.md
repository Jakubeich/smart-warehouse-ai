# Project guidance

Keep Python simulation authority separate from React rendering. All movement passes the central invariant validator. Do not substitute prioritized planning for CBS, silently fall back on planner failures, or invent measured data. Keep deterministic logical time independent of display speed. Update IMPLEMENTATION_PLAN.md with verification and limitations. Use uv in apps/backend and npm in apps/frontend. Run pytest, Ruff, mypy and frontend build/tests after relevant changes. Database schema changes require Alembic migrations. The user has authorized a switchable 3D presentation layer and Blender asset preparation. Both renderers consume the same authoritative snapshots; switching views must never mutate or restart a simulation. Blender models affect appearance only, not movement, collisions or experiment metrics.
